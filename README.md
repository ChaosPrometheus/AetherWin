# AetherWin

Лёгкий менеджер окон для Windows.

Быстро закрепляй окна поверх всех, меняй прозрачность, сохраняй и восстанавливай раскладки. Работает в системном трее и поддерживает глобальные горячие клавиши.

## Возможности

- 📋 Список всех открытых окон
- 📌 Always on Top (поверх всех окон)
- 👻 Прозрачность окон (20–100%)
- 💾 Сохранение и восстановление раскладок
- ⌨️ Глобальные горячие клавиши
- 🔽 Работа в системном трее
- 🎨 Современный тёмный интерфейс

## Горячие клавиши

| Комбинация           | Действие                              |
|----------------------|---------------------------------------|
| `Ctrl + Shift + T`   | Always on Top у активного окна       |
| `Ctrl + Shift + ↑`   | Увеличить прозрачность активного окна |
| `Ctrl + Shift + ↓`   | Уменьшить прозрачность активного окна |
| `Ctrl + Shift + W`   | Показать / скрыть главное окно        |
